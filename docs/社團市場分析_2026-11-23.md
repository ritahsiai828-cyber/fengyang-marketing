# 社團與機關市場：對手賣點與我們的優勢（2026-11-23，小編）

> 給發文手：做社團專區頁面、寫社團相關貼文前先看這份。重點是「對手賣散客，我們賣整團代辦」。

## 結論
四個市場的對手都在賣「散客團」或「公開行程」，沒有人專門做「幫主辦人辦整團」。我們的文案一律站在**主委、總幹事、社長、人事室**的角度：幫他們省事、讓他們好交代。

## 一、宮廟進香・遶境
- 關鍵字（Ubersuggest 台灣，2026-11-22）：大甲媽祖遶境每月約 33,100（每次點擊約 NT$33、競爭度 0.03）；進香團 880、媽祖進香 320，幾乎沒人投廣告。搜「媽祖遶境 行程」前排是 IG、PChome、攻略網站，沒有旅行社包團頁。
- 規模：2026 白沙屯媽祖進香報名人數達 46 萬（遠見城市學 2026-04-13）。
- 對手賣點：
  - 東南：散客一、二日遊，任選日期與出發地，會員送大甲媽祖紀念帽、豬羊份、獻疏文（名字在祝壽典禮誦念），抽紀念酒（食尚玩家 2026-03-06）。
  - 雄獅：1～3 日遊，都安排徒步跟隨白沙屯媽祖的體驗時間（食尚玩家）。
  - 廟方：白沙屯有 8 天步行專用遊覽車，團體直接洽拱天宮服務台（聯合新聞網）。
  - 宮廟自辦：常只包遊覽車跑行程，業者指出出事時沒人負責（風傳媒）。
- 我們的切角：
  - 從你的廟埕出發，整團客製
  - 依長輩體力分段陪走，搭配香客大樓或飯店
  - 每人一份繳費單、數位報名，總幹事不用收現金
  - 合法旅行社承辦、保險說清楚 → **執照字號放回網站後才能寫**
- 不要做：比價格、送贈品抽獎（那是散客打法，也違反不寫價格的規則）

## 二、服務性社團（扶輪、獅子、青商、BNI）
- 關鍵字：「扶輪社 年會」「參訪團」幾乎沒有搜尋量 → 靠人脈，不靠 Google。
- 需求實例：扶青社赴菲律賓與姐妹社交流例會（蕃新聞 2026）；扶輪月刊鼓勵社員參加國際年會時順道旅行。
- 對手：網路上看不到主打這塊的業者，多半是社員自己的旅行社或熟人介紹。
- 我們的切角：不只賣行程，賣「交流活動整包代辦」——例會場地、文化節目、授證交接典禮；沿用激勵旅遊頒獎晚宴經驗。
- 不要做：放扶輪、獅子、BNI、青商會的 logo（商標）。

## 三、高爾夫球隊
- 關鍵字：高爾夫 旅遊每月約 70，每次點擊約 NT$18。量小、客單高。
- 對手賣點：專門社（如東豪「日本高爾夫旅遊專家」）靠說明會與日本球場、縣政府關係（工商時報）；航空公司聯合旅行社辦比賽團——星宇神戶團台北、台中各限量 32 席（旺得富）、長榮愛媛團與雄獅等四家合作（聯合報）。共同賣點：名門球場、比賽、溫泉美食、早鳥與老球友折扣、限量。
- 我們的切角：公開團是陌生球友拼團；球隊要的是自己的活動 → 球隊包團＋隊內盃賽＋頒獎晚宴。
- 前提：先找到能訂球場的日本或泰國當地合作夥伴，不然先不推。

## 四、公家機關
- 關鍵字：自強活動每月約 320，沒人投廣告。
- 對手：小型旅行社投標，多半拼價格（例：法務部行政執行署員工旅遊採購案由一家旅行社得標）。
- 突破口：臺中市政府人事處的內控規定要求「各機關應自行建立自動化投票系統，適時統計同仁投票意見」→ 我們的數位問卷可以直接幫人事室完成行程投票。
- 前提：投標需旅行業執照 → 執照字號確定前不做。

## 兩個要先補的弱點
1. 執照字號：宮廟的信任和公家標案都卡在這裡。
2. 不拚價格：主打「幫主辦人省事」。

### 給發文手的貼文方向（宮廟／社團）
1. 「進香團幕後」短片：遊覽車出發、香客大樓、領隊點名（遮臉）
2. 「總幹事懶人包」輪播：收團費、長輩體力、名單保險、理監事會比較表
3. 2027 遶境日期公布後：日期圖卡＋「整團包車找我們」，搭配加 LINE
4. 不做：價格、贈品抽獎、政治或爭議話題（如搶轎衝突）、未經同意的人臉
