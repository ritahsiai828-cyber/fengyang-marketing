## 0. 先讀：怎麼省點數

1. **不要用 Wix 的 AI 建站功能。** 全部用 Wix 編輯器手動拖拉，文案直接從本檔複製貼上。
2. **從現有的 /blank-1（員工旅遊頁）複製一頁**（頁面選單 → 複製），保留導覽列、頁尾、表單，再改內容。比從零開始快很多。
3. **本檔已經寫好所有文字、版面、顏色、圖片來源**，不需要再研究或改寫。不確定的地方寫在 issue 問，不要自己補內容。
4. 一次只做一頁：先做「宮廟進香與遶境」（第 3 節），做完截圖貼在 issue，再做母頁。
5. 小編的 Wix 連接器連不到鳳洋行天下網站，所以頁面只能由發文手建；遇到卡關就在 issue 問，小編改規格或補素材。

## 1. 共用設計規則（兩頁都適用）

| 項目 | 規格 |
|---|---|

| 段落標題 | 宋體類（思源宋體／Noto Serif TC），大寫英文副標用細字加大字距 |
| 內文 | 黑體類（思源黑體／Noto Sans TC），16–18px，行高 1.7 |
| 撕紙邊 | 每個段落之間放一條「撕紙邊」PNG（Canva 搜尋 torn paper edge，白色與米白各做一張，1920×120，透明背景）。放在段落底部，蓋住下一段頂端 |
| 照片 | **只用遮臉版**：Canva 資料夾「歐巴馬｜客戶實拍素材（已遮臉）」https://www.canva.com/folder/FAHaTxMTc4c 。照片裡不能看得到宮廟或社團名稱、人臉、車牌 |
| 禁止 | 價格、「保證」、「最」字級、任何人全名、客戶或宮廟名稱、社團標誌（扶輪、獅子、BNI、青商會的 logo 都不能放）、執照字號（待確認） |
| 手機版 | 每段做完都切到手機版檢查：標題字圖不能超出畫面、日期清單改成橫向兩欄 |

## 3. 宮廟進香與遶境（/club-temple）

### 段落 1｜主視覺（參考圖第一段）
- 版面：全版寬、高度 100vh；暗色照片＋上方 30% 黑色漸層遮罩
- 照片：Canva 遮臉素材中「團體在廟前或遊覽車旁」的照片；沒有就用遶境人群的遠景（看不到臉）
- 主標（書法字圖）：**宮廟進香・遶境包團**
- 副標（白字，宋體）：主委、總幹事交給我們，信眾安心出發
- 小字（金色）：擁有 30 年經驗｜5 人以上團體客製
- 按鈕 1（品牌色實心）：索取進香行程 → 連到本頁表單
- 按鈕 2（白框）：加 LINE 問行程 → https://lin.ee/8t6tq8e
- 底部：白色撕紙邊

### 段落 2｜選擇行程（參考圖第二段）
- 小標（金色，加大字距）：CHOOSE YOUR ROUTE
- 段落標題（宋體）：選擇你的進香行程
- **Wix「分頁（Tabs）」元件**，3 個分頁：

| 分頁名稱 | 背景照片 | 大標（宋體，48px，白字） | 說明（白字） | 右側清單標題 | 右側清單內容 |
|---|---|---|---|---|---|
| 跟媽祖遶境 | 遶境人群夜景或白天遠景 | 跟媽祖遶境 | 大甲媽祖遶境、白沙屯媽祖進香，由我們安排遊覽車、住宿與用餐，跟隨鑾轎的段落依體力分組安排。 | 2027 遶境日程 | **廟方公布後更新**（先放一行：「日程公布後，加入 LINE 第一時間通知你」） |
| 宮廟交陪進香 | 廟埕或遊覽車團體照 | 宮廟交陪進香 | 依宮廟的進香路線與時辰規劃行程，安排遊覽車、香客大樓或飯店、團體用餐，讓總幹事只要確認名單。 | 常見安排 | 一日進香／二日進香＋住宿／多宮廟串連 |
| 信眾旅遊 | 團體出遊照 | 信眾年度旅遊 | 宮廟年度旅遊、志工慰勞旅遊，國內外都可以依人數和長輩體力客製。 | 適合 | 志工慰勞／爐主交接／年度旅遊 |

- 每個分頁左下角按鈕（白框）：這個行程我有興趣 → 表單
- 右側清單用「大號數字＋小字」排版（參考圖的日期欄）：大字 40px 宋體白色，小字 14px 金色
- 底部：米白撕紙邊

### 段落 3｜總幹事最常煩惱的事（淺色段落）
- 背景：米白 #F0E7D8
- 段落標題：辦進香，最累的是這些事
- 4 張卡片（2×2，手機版 1 欄），每張：金色細線＋標題＋一句話

| 標題 | 內容 |
|---|---|
| 收團費 | 我們提供每人一份繳費單與收據，信眾各自繳費，總幹事不用收現金。 |
| 長輩體力 | 行程節奏放慢、安排休息點與無障礙動線，需要時可安排輪椅與醫療資訊。 |
| 名單與保險 | 數位報名表收齊名單，團體保險依需求客製，出發前名單一次確認。 |
| 理監事會決議 | 給你一頁「行程比較表」，2～3 個方案並排，開會時直接討論。 |

### 段落 4｜為什麼交給我們（暗色段落）
- 背景：深炭黑；左文右圖
- 標題：一個窗口，從規劃到回程
- 條列（白字，金色圓點）：
  - 同一位專人從需求跟到出發
  - 整團專屬領隊
  - 行前說明會
  - 回程後提供照片與結案紀錄
- 右側照片：遮臉團體照
- 底部：白色撕紙邊

### 段落 5｜出團紀錄（參考圖第三段：拼貼）
- 小標：TRIP STORIES；段落標題：出團紀錄
- 版面：左邊一張文字卡（白底），右邊 2 張照片；其中一張照片上壓大標（白字宋體）
- 文字卡內容：每一團回來，我們都會整理照片與紀錄交給主辦單位，成為下一年規劃的參考。
- 照片上的大標：**交陪進香紀實**（不要寫宮廟名稱）
- 照片來源：Canva 遮臉素材，挑 2 張
- ⚠️ 不寫任何宮廟名、地名到廟的層級、人名

### 段落 6｜流程（淺色段落）
- 標題：五步驟，出發前全部搞定
- 橫向 5 步（手機版直排），每步一個大號數字：
  1. 加 LINE 或填表，告訴我們人數、日期、要去哪
  2. 收到行程比較表
  3. 理監事會決議
  4. 信眾報名、各自繳費
  5. 出發，回程交紀錄

### 段落 7｜表單（沿用 /blank-1 的表單元件）
- 標題：索取進香行程
- 欄位（只留這些，越短越好）：
  - 聯絡人稱呼（必填）
  - 手機（必填）
  - LINE ID
  - 團體類型（下拉，必填）：宮廟／服務性社團／商會協會／宗親校友會／運動興趣社團／其他
  - 預計人數（必填）
  - 預計月份
  - 想去的地方或需求（多行）
- 送出後顯示：「已收到，我們會在 1 個工作天內聯絡你。也可以直接加 LINE：https://lin.ee/8t6tq8e」
- 表單通知寄到 obamatravel2009@gmail.com（同現有設定）
- ⚠️ 表單收到的資料**不能**放進 GitHub repo，也不要貼給 AI

- 描述：宮廟進香、跟媽祖遶境、信眾年度旅遊包團。每人一份繳費單、長輩友善節奏、整團專屬領隊，主委與總幹事一個窗口搞定。
